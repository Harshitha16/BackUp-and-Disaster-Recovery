
# Veeam Backup Configuration

Step 1: Install Veeam Backup & Replication.

Step 2: Add virtualization host.

Step 3: Add backup repository.

Step 4: Create backup job.

Backup settings:

- Backup type: VM-level
- Schedule: Daily incremental
- Weekly full backup
- Retention: 14 restore points

Step 5: Run initial backup job.
